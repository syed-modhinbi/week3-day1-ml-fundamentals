# Week 3 Day 1 - Machine Learning Fundamentals

## Overview

This project demonstrates the basic Machine Learning workflow using Python and Scikit-learn. A Linear Regression model is built to predict student marks based on study hours, attendance, and assignments.

## Dataset

The dataset contains the following columns:

- Study_Hours
- Attendance
- Assignments
- Marks

Target Variable:

- Marks

## Tasks Completed

### Part 1 - Dataset Exploration
- Loaded dataset
- Displayed first and last 5 rows
- Checked shape and columns
- Checked data types
- Generated summary statistics

### Part 2 - Features and Label
- Selected features (Study_Hours, Attendance, Assignments)
- Selected label (Marks)

### Part 3 - Machine Learning Workflow
- Documented ML workflow steps

### Part 4 - Train-Test Split
- Split dataset into 80% training and 20% testing

### Part 5 - Linear Regression Model
- Trained Linear Regression model
- Displayed coefficients and intercept

### Part 6 - Predictions
- Predicted marks for new student data

### Part 7 - Actual vs Predicted Comparison
- Compared actual and predicted marks
- Calculated prediction differences

### Part 8 - Model Evaluation
- Calculated Mean Absolute Error (MAE)
- Calculated R² Score

### Part 9 - Data Visualization
Created the following Plotly visualizations:
- Study Hours vs Marks
- Attendance vs Marks
- Assignments vs Marks
- Regression Line Visualization
- Predicted Marks Trend

### Part 10 - Research Activity
- Machine Learning
- Linear Regression
- Features
- Labels
- Training Data vs Testing Data
- Real-world Applications of Machine Learning
